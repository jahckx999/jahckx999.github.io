Entrar no painel

Só quem tem a chave do GitHub consegue alterar a vitrine. A chave fica guardada apenas neste aparelho — nunca vai para o site.

Como criar a chave (1 vez só, 2 minutos)
  1. Abra github.com › Fine-grained token.
  2. Nome: Painel Kaelenvash · Validade: 1 ano.
  3. Repository access: Only select repositories → jahckx999.github.io.
  4. Permissions › Contents: Read and write.
  5. Clique em Generate token, copie e cole aqui.

Se um dia perder o celular, é só apagar a chave no GitHub — o painel trava na hora.
