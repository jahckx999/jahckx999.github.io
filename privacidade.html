1. Quem usa este aplicativo

Este aplicativo é de uso pessoal e exclusivo do seu proprietário. Ele não é oferecido ao público e só acessa a conta Google do próprio dono, com autorização dada por ele.

2. Quais dados do Google são acessados

  • YouTube: enviar e agendar vídeos no canal do proprietário e ler estatísticas públicas do canal (inscritos, visualizações e número de vídeos).
  • Google Drive: ler e gravar arquivos nas pastas do próprio projeto (roteiros, músicas e vídeos montados).
  • Google Planilhas: ler e atualizar a planilha de controle do projeto.
  • Gmail: enviar avisos por e-mail somente para o próprio proprietário. O aplicativo não lê e-mails.

3. Como os dados são usados

Os dados são usados apenas para montar os vídeos, publicá-los no canal do proprietário depois da autorização dele e enviar avisos sobre esse processo. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

4. Armazenamento e segurança

Os arquivos ficam no Google Drive do próprio proprietário. As credenciais de acesso ficam guardadas como segredos criptografados no GitHub e nunca são publicadas.

5. Política de Dados do Usuário das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O uso dos dados do YouTube também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

6. Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
